Why there are no screenshots

This system holds information about students and families. We show how it fits together, not what's inside it.

The challenge

The school already had its core system in place, and replacing it was never the goal. What it needed was for that system to do more, and to fit the way staff and families actually use it, without putting sensitive student data at risk.

What we built

Portals
Pages for students, guardians and staff, designed around what each of them needs to do.
Tools inside the existing system
Extensions that work with the school's platform rather than around it.
Data and permissions
Access rules so every person sees what they should and nothing more.

The result

The school keeps the system it knows, and it now works the way the school needs it to.
